# Missão: Engenharia de Prompts como competência profissional

## Porquê

Capacitar profissionais para deixarem de tratar o prompt como uma frase isolada e passarem a desenhar interações, contextos e sistemas de instruções que resolvem tarefas reais com qualidade controlável.

## O sucesso é demonstrado quando o formando consegue

- diagnosticar uma tarefa antes de escrever o prompt;
- selecionar contexto, dados, exemplos, critérios e restrições relevantes;
- aplicar a Tríade DSK e o Método PROMPT a casos profissionais;
- construir e comparar diferentes estratégias de prompting;
- avaliar outputs com critérios explícitos e casos de teste;
- criar um sistema de prompts documentado, reutilizável e preparado para evolução.

## Restrições

- O curso deve ser independente de uma única plataforma ou modelo;
- As técnicas devem ser distinguidas entre modelos generalistas, modelos de raciocínio e agentes;
- As lições devem ser curtas, práticas e utilizáveis em formação síncrona ou assíncrona;
- O conteúdo deve usar português de Portugal;
- Cada lição deve produzir uma competência observável, não apenas exposição teórica.

## Fora do âmbito

- treino de modelos fundacionais;
- matemática detalhada de transformers;
- fine-tuning técnico completo;
- desenvolvimento integral de aplicações por API;
- promessa de fórmulas universais de prompt que funcionem em todos os modelos.
