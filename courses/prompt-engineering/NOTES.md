# Notas pedagógicas

- O curso representa o posicionamento de Duarte Drumond: “O prompt não começa no teclado”.
- O Método PROMPT usa as fases: Pensar, Refletir, Otimizar, Moldar, Passar e Testar.
- A Tríade DSK deve ser apresentada como a combinação entre conhecimento do domínio, domínio semântico/linguístico e conhecimento técnico da interação com IA.
- Evitar ensinar listas rígidas de parâmetros como se fossem receitas universais.
- Separar boas práticas transversais de comportamentos específicos de cada modelo.
- Usar casos empresariais reais: análise, decisão, marketing, RH, documentos, processos, agentes e automações.
- Não usar a redação de e-mails como caso principal; é demasiado simples para demonstrar Prompt Engineering.
- Cada lição termina com: recuperação ativa, aplicação, rubrica de autoavaliação e ponte para a próxima lição.
- Apenas criar learning records depois de o formando demonstrar aprendizagem.
