Prompt Engineering não é escrever prompts

O prompt é o ponto visível de um trabalho anterior: compreender o problema, escolher informação, definir sucesso e prever falhas.

A distinção essencial

Prompting é interagir com um modelo. Prompt design é estruturar uma instrução para obter determinado comportamento. Prompt Engineering é desenhar, testar, avaliar, documentar e integrar essa interação num processo que precisa de funcionar mais do que uma vez.

O que existe antes do teclado

Uma tarefa profissional exige diagnóstico: objetivo, utilizador, dados disponíveis, decisões permitidas, risco de erro, formato de utilização e critérios de qualidade. Sem isto, acrescentar “age como especialista” apenas disfarça a indefinição.

Aplicação

Escolhe uma tarefa real do teu trabalho. Antes de escrever qualquer prompt, completa: decisão ou resultado pretendido; informação necessária; erro mais caro; pessoa que usará o output; evidência de que a resposta está correta.

Recuperação ativa

Critério de domínio

  • Não confundes comprimento com qualidade.
  • Consegues identificar trabalho de diagnóstico anterior ao prompt.
  • Consegues definir um resultado observável.
