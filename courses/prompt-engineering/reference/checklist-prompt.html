Checklist de construção de prompts

  1. O resultado pretendido está definido?
  2. A tarefa é adequada ao modelo e às ferramentas disponíveis?
  3. O contexto necessário foi selecionado?
  4. Os dados estão separados das instruções?
  5. Os termos ambíguos foram definidos?
  6. Existem critérios de qualidade observáveis?
  7. As restrições são relevantes e compatíveis?
  8. O formato do output corresponde à utilização seguinte?
  9. São necessários exemplos?
  10. Existe tratamento para ausência, conflito ou incerteza?
  11. Foram previstos riscos e revisão humana?
  12. Há casos de teste e uma forma de comparar versões?
Regra: não acrescentes componentes por hábito. Cada elemento deve resolver uma necessidade ou reduzir um risco.
